Navigation (branch: cursor/navigation-4ff9)
============================================

Task
----
Add shared navigation on pages where it helps orientation (lobby, room) and a way to leave finished games.

Approach
--------
- AppNav (client): breadcrumb-style links — End Word → Lobby → Room (on /room/*). Hidden on `/` so the name-entry screen stays focused.
- AppShell wraps all pages inside SupabaseProvider in layout.tsx.
- GameOverlay: "Back to lobby" on finished state; Game.tsx wires router.push("/lobby").

Key files
---------
- src/app/components/AppNav.tsx — nav UI, pathname-aware active states, player name display, "Change name" → /?changeName=1
- src/app/components/AppShell.tsx — mounts AppNav above children
- src/app/layout.tsx — wraps children with <AppShell>
- src/app/components/GameOverlay.tsx — onBackToLobby prop + button in finishedJsx (~lines 41–58)
- src/app/components/Game.tsx — passes onBackToLobby to GameOverlay

Decisions
---------
- No nav on home: avoids clutter during first visit.
- Lobby link always /lobby; unauthenticated users are handled on the auth-redirect branch.
- changeName=1 query reserved for auth branch to pre-fill/clear name on return home.

Outcome
-------
Lobby and room pages have consistent top navigation; finished games can return to lobby without browser back.
